# Geometry Dash Style Game

A simple browser-based platformer inspired by Geometry Dash.  
The player jumps over obstacles while the level scrolls automatically, aiming to survive as long as possible.

## Overview

- Fast-paced auto-scrolling gameplay  
- Jump to avoid spikes and obstacles  
- Lightweight HTML, CSS, and JavaScript  
- Easy to modify for custom levels or visuals  

## Project Purpose

This project is an experiment in building a small, responsive, canvas-based game.  
It focuses on basic physics, collision detection, and smooth animation timing.

## Status

Actively being improved with new features, visuals, and gameplay tweaks.
